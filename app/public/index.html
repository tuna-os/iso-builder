Your custom TunaOS ISO is ready. Now you need to write it to a USB drive to make it bootable.

  1. Download and install BalenaEtcher (supports Windows, macOS, and Linux).
  2. Plug in your USB flash drive (minimum 4GB).
  3. Open Etcher, click Flash from file and select your downloaded TunaOS ISO.
  4. Select your USB target and click Flash!.
  1. Install Ventoy onto your USB flash drive (non-destructive; you only do this once).
  2. Once Ventoy is installed, your USB drive will show up as a normal partition named Ventoy.
  3. Simply drag and drop your downloaded TunaOS ISO file directly onto the USB partition.
  4. Reboot your PC, boot from the USB drive, and choose the ISO from the Ventoy menu.
  1. Download and open Rufus (Windows only).
  2. Select your USB drive under Device.
  3. Click SELECT and choose your downloaded TunaOS ISO.
  4. Keep default settings (GPT, UEFI) and click START.
  5. If prompted for write mode, select Write in ISO Image mode.

Warning: writing to the wrong drive wipes it. Check the device name first.

  1. Identify your USB drive name (e.g. /dev/sdX on Linux, /dev/diskN on macOS).
  2. Run the following command in your terminal: 
    sudo dd if=path/to/tunaos.iso of=/dev/sdX bs=4M status=progress oflag=sync
  3. Wait for the write command to complete and safely eject the drive.
