ISO build complete

Your custom ISO is ready. Now you need to write it to a USB drive to make it bootable.

  1. Download and install BalenaEtcher (supports Windows, macOS, and Linux).
  2. Use a USB drive with capacity larger than the downloaded ISO file. Back up its files and verify the selected drive before flashing; flashing erases its contents.
  3. Open Etcher, click Flash from file and select your downloaded ISO.
  4. Select your USB target and click Flash!.

Warning: Normal Ventoy installation reformats the selected USB drive and erases all its data. Back up its files and verify the target drive before you install.

Check your edition's USB-writing instructions first. Bluefin recommends Fedora Media Writer and does not support Ventoy.

  1. If Ventoy is already installed, do not reinstall it to add this ISO. Otherwise, follow the Ventoy installation instructions after the backup and target check above.
  2. Open the USB drive's Ventoy data partition, normally named Ventoy, and check that its free space exceeds the ISO file size.
  3. Copy your downloaded ISO file onto that data partition.
  4. Reboot your PC, boot from the USB drive, and choose the ISO from the Ventoy menu.
  1. Download and open Rufus (Windows only).
  2. Select your USB drive under Device.
  3. Click SELECT and choose your downloaded ISO.
  4. Keep default settings (GPT, UEFI) and click START.
  5. If prompted for write mode, select Write in ISO Image mode.

Warning: writing to the wrong drive wipes it. Check the device name first.

  1. Identify your USB drive name (e.g. /dev/sdX on Linux, /dev/diskN on macOS).
  2. Run the following command in your terminal: 
    sudo dd if=path/to/image.iso of=/dev/sdX bs=4M status=progress oflag=sync
  3. Wait for the write command to complete and safely eject the drive.
